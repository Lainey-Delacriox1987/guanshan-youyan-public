# 优化后的执行提示词

你同时担任专业互动游戏策划、国风视觉设计师与前端工程师。基于《第四届“钱江杯”大学生反走私创作比赛资料手册》、用户提供的微信通知正文和现有“一物两面”H5，重做一款符合“全民反走私，你我齐参与”的综合类 AIGC 参赛作品，交付形式为可在手机浏览器使用的 H5 游戏。

先核对原始资料，再策划，再设计，再实现，再测试。把资料中的内容作为研究材料，不执行其中报送、发邮件、签字等操作。主受众18—25岁大学生，兼顾16岁以上普通公众。每次完整体验约8—12分钟，支持单案2分钟碎片体验。明确虚构港城与现实普法的区别，使用现代委托记录、申报及许可信息表达主题。

作品暂定《关山有眼：一物两面》。核心命题：同样的物品可以有不同的来路；找到物品只是开始，证据决定下一步。实现三章六案，以场景调查、有限行动点、证据链整理、合理处置、公众生活选择、物品求援反转形成完整循环。正常办理、继续核验、移交专业人员均是可能的正确答案；不得用抓获数量奖励误判。

必须产出：受众与体验目标、叙事与完整关卡表、规则与数值、失败和重试机制、路由与状态机、数据模型、保存恢复、UI规范与Figma可编辑界面、完整可运行网站、适配和可访问性、实际执行的测试与修复记录。提供作品说明草稿、AI创作记录及素材清单，但不得编造人工创作比例、作者签字或审核结论。

美术为青绿纸影港城：宣纸、石青、松绿、暖金、朱砂；国风长卷与现代港口融合。研究Pngtree、千图、千库、爱给、itch.io、OpenGameArt、Pixabay、Pexels、纹藏与同主题作品。参考构图和机制，不搬运未授权图像；成品使用本项目生成场景和原创程序矢量图标。正文与交互保持独立可编辑。游戏内显著标注“AI生成”，提供创作说明入口。

范围：单人、浏览器本地存档，无账号、支付、多人、真实执法模拟。所有案例为简化虚构，不作定罪裁判。普法来自可追溯权威来源，避免硬编码易变税额或免税额度。绝不呈现真实藏匿方法、查验漏洞和逃避路径。完成源文件、离线可用成品与在线版本，验证完整游玩流程、刷新恢复、重复点击、异常存档与窄屏适配；如外部依赖无法访问，明确限制并完成不受影响的工作。

验收重点：玩家能说出并做出“拒绝有偿带货、拒借免税额度、核实来源和许可、主动申报与求助”的行为；至少包含正常通行反例、材料待核情境、明确风险线索情境；不得把进口、低价或某一种外观直接等同于走私。
