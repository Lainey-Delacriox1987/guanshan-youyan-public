# 行走探索与对话推进版规划（2026-10-27，先规划后执行）

## 目标

根据用户提供的横向探索游戏截图，升级为可行走、可上下楼、可进门、靠近后调查和选择对话推进的反走私游戏。参考空间组织与交互，不复制截图中的角色、剧情、UI或素材。四幕案件、证据推理、科普卡、双结局继续完整可玩。

## 设计与实现顺序

1. 横向场景：每章一个可跟随镜头探索的场景，门连接室内外区域，行走途中连续改变位置与朝向。各章提供两处可往返区域。按用户补充，只有仓库用楼梯连接二层调度室；港口通过平地闸口/查验门，小镇使用店门/后门双入口，审讯区使用走廊/档案门，不复制同一套路线。
2. 双端操作：电脑左右键/A、D移动，E/空格与最近目标交互；手机点击地面移动，点击物件自动走近后交互，另提供触控方向键。输入框、弹窗、失焦时暂停行走并清空按键。
3. 对话推进：角色立绘、说话者、逐句内容、下一句和选择分支；用原有NPC话题和关键证据推进案件。未取得的证据不能用于质询。无需联网AI、无需额外账号。
4. 过渡：进门/上下楼/章节出发均有明确的地点标记和过渡，结束后可以返回。未完成材料与推理时不允许跳关。
5. 美术：新增与反走私主题一致的原创行走角色和无人物场景，保持清晰素材；既有高清插画用于标题、案卷等页面。按关卡加载，不一次下载所有大图。
6. 存档：保留guanshan-mist-v1案件存档，新增独立且校验过的区域/位置记录；返回标题、切换工具页、刷新后可继续。新故事清理对应探索记录。
7. 验证：键盘持续移动、点地行走、目标接近、楼梯高度、门往返、镜头、对话与证据、失焦/弹窗/触控取消、手机横竖屏及四关双结局。完成本地验证后覆盖原Netlify站点并核实线上实际行为。

## 验收线

最新目标版本按用户指定为V1.0.2。用户追加要求：黑色参考图是叙事过场，不是空白占位。新增原生黑底白字过场，分别放在开场任务交代、港口至仓库、仓库至小镇、小镇至调查中心，以及最终提交判断前；内容使用本作案件事实，不照搬参考游戏的幽灵、谋杀、15分钟倒计时或英文文案。重要过场可逐句继续或跳过，普通房门只短暂过渡，不重复播放长段说明。

- 人物确实连续移动，镜头跟随；操作不是一按就换背景。
- 门和楼梯能往返，不只是装饰；近距离才能触发现场调查。
- 手机不用键盘也能完成全部剧情，文字与交互按钮不挡住主要行走区域。
- 现有12份证据、3张科普卡、4项最终判断、双结局及旧存档继续有效。
- 减少动态设置下保留必要移动反馈，弱网和图片失败不呈现半张或模糊背景。
