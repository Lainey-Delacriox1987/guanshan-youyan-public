# V1.0.2 左右脚步态调整

用户澄清需求：人的走路姿势，左右脚交替走。原动作图中多个跨步姿势重复，动画只在三张相近姿态间往返，视觉上容易像滑动。

本次使用内置image_gen重做动作图，保留林见身份、制服、画风；补画反向摆臂及另一侧腿支撑的半个周期。透明帧按头部位置和脚底基线归一化，过滤相邻格子溢出的零散部分。原图与最终atlas均保留在h5/public/assets/walk。

最终为3×3动作图：第0帧站立，第1至8帧连续循环。左右移动镜像整个人物。动画按实际移动路程推进，不按绝对时间原地切帧；停止移动恢复第0帧。两步之间增加不超过1.4虚拟像素的轻微起伏。楼梯按实际斜向路程推进。对话中的林见立绘同步读取新的站立格，手机布局不裁人物头部。

保留自然交互调整：现场无常驻绿色圆圈，靠近或点击物品反馈不变，四关、八区域、证据与旧存档不变。

验收：49项单元/资源/路线检查、51项完整浏览器流程、17项加载检查、8项步态专项检查均通过。专项实际观察到0至8全部帧，覆盖右走、左走、松键、对话暂停、手机按住及取消触控。源码工具为h5/tools/prepare-walk-gait.cjs，完整提示词与两次生成来源为output/walk-gait-generation.json。

输出：h5/public/assets/walk/player-gait-atlas.png；实际游戏行走预览output/V1.0.2-游戏实际行走.gif；动作循环预览output/V1.0.2-左右脚步态.gif；浏览器结果output/V1.0.2-步态验收.json。

重建动作图时，运行prepare-walk-gait.cjs作为素材清单的最后一步，避免被早期四帧素材生成脚本覆盖。
