# V1.0.2 自然交互调整

按用户反馈移除现场常驻绿色圆圈、放大镜、人物/门等悬浮符号。调查、证据、人物、手记功能保持原位置。

现场平时显示场景、人物和实际物品。透明点击区域覆盖人物身体、门和物品，不再要求点击空中的符号。走近、鼠标移入或键盘聚焦时，物品出现淡暖色高亮与名称；附近人物轻微提亮。点击目标有短暂视觉回应，玩家走近后触发调查、对话或进门；电脑仍可按E/空格与附近目标交互。靠近只提示，不自动提交推理或归档证据。

保留“目标与地点”折叠目录，避免去掉标记后难以查找目标。手机可直接点击物品或人物；空地点击继续行走。

验收：48项单元/媒体/路线检查通过，51项完整浏览器流程通过；额外6项检查覆盖无常驻符号、远处不显示名称、靠近反馈、点击物品、无图标进门和手机点击比对。完整流程中，手机空地测试改点真正的地面，避免把现在可以点击的人物当作空地。
