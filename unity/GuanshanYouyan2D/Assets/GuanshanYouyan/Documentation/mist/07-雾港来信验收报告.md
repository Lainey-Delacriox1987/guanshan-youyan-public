## 结果

- npm test：37/37项通过，包括旧版26项和新版11项。
- npm run build：成功，生成dist静态离线成品。
- Chrome真实浏览器验收：36项通过；从最终dist/index.html出发，按真实按钮依次调查港口、仓库、小镇和审讯室，取得12份证据并分别进入警示与成功结局。

- 已验证本地HTTP预览 http://127.0.0.1:4190 返回200且显示可游玩的标题页。

## 关键行为

未解锁关卡不可访问；比对错误不给证据；对话关键记录可归档且不重复；收齐材料后才允许推进；错答提示与重试保留资料。关闭案例卡后可重新打开继续推进；历史案例卡也可从手记重看。

刷新后保留证据、对话、备忘和结局；取消新故事保留当前存档；回访旧现场后可返回当前调查；禁用localStorage后仍可完成本次调查，并显示不能存档提示。个人备忘以文本转义显示。残缺/不一致存档会净化，结局按保存的判断重算。

最终判断需完成四项选择。选择不完整不能提交；任一项错误进入警示结局，修正后能进入成功结局；12份证据不丢失。

## 布局范围

Chrome桌面1440×900、触屏竖屏390×844、横屏844×390。已检查各主要界面的横向溢出。竖屏单证采用上下两页，线索板、地点地图和手记可滚动；横屏采用紧凑导航并保留场景空间。弹窗支持Esc关闭，按钮可通过键盘Tab/Enter操作。系统“减少动态”偏好和游戏动态开关可停用动效。

## 第一版边界

美术为4张生成式AI背景与程序生成的界面；对话采用文字与轻提示音，无真人配音。疑似野生动物制品为独立线索，不因外观直接判定物种。真实案例与游戏情节分别说明，并保留来源与地域。当前在Chrome完成实际验收，未在真机iOS/Safari上实测；不包含后端、多人模式或账号同步。file协议能否跨次保存由浏览器决定，建议HTTP托管以获得稳定存档。
