# 《关山有眼：雾港来信》第一版实施规划

日期：2026-10-26。范围：可离线游玩的完整四关连续剧情 H5。

## 体验与视觉
以用户提供的九张图片作为风格参考：暖金夕照、现代港口、深红皮质案卷、旧纸、黄铜边框、调查红线。画面采用横向舞台，桌面沉浸式展示，手机横屏优化，竖屏仍可操作。所有按钮、文字和热点均为真实 DOM 交互，不以界面截图代替功能。

## 故事
玩家是实习调查员林见，由带教人员许岚指导调查编号 QJ-017 的异常货柜。实际货物为进口化妆品，同时发现一条涉及疑似濒危动物制品的旁支线索。以“码头异常—仓库拆单—小镇收货—审讯汇总”串联完整链条。所有人物与案情为虚构。

## 四关递进
1. 港口码头《不一样的重量》：报关单申报日用收纳盒 800kg，地磅复核 1260kg；封条二次粘贴；依法查验发现化妆品；交接记录指向顺达仓库。点击证据并在比对面板确认异常，向值班员问询。选择“暂缓放行并报请查验”，获得真实案例卡。
2. 物流仓库《被拆散的去向》：比对三张运单的相同批次 K17 与不同收件名、监控中的同一车辆、转运登记中的实际地址，问询仓管后定位青禾镇17号。确认是同批货物拆分并集中转运，而非单凭小包裹判断走私。获得“化整为零”案例卡。
3. 边境小镇《不合时宜的橱窗》：走访店主苏禾、快递员周叔、货运负责人陈渡；店内批次与仓库一致，陈渡的否认与签收、付款记录冲突；另查疑似野生动物制品，交专业人员核验。将组织者、收货点、货物关系串联。获得消费者与生态保护案例卡。
4. 最终审讯室《让证据说话》：询问嫌疑人，选择主导者、走私手法、关键证据链、处置建议；提交后依据证据与答案进入“雾散港明”或“未闭合的链条”。失败可保留调查资料重新推理。
