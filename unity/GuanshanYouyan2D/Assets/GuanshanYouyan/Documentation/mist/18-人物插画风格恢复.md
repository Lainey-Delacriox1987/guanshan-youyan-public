# V1.0.2 人物插画风格恢复

用户确认骨骼步态已正确，但明确指出基础低模人物与原作相差过大。本次保留已确认的走路曲线和速度，只重做人物外观与显示方式。

## 美术

以原始 `player-source.png` 和 `cast-source.png` 为身份、制服和画风参考，使用 OpenAI 内置 image_gen 制作人物插画部件。保留年轻黑发侧脸、浅蓝短袖制服、领口、肩章、胸袋、黑腰带、深色长裤及黑皮鞋。单独修正躯干部件的空袖口，以免摆臂时露出假袖子。

源图：`h5/design/motion-reference/LinJian-illustrated-parts-alpha.png`；修正躯干：`LinJian-illustrated-torso-edit.png`。完整提示词及生成路径见 `output/illustrated-character-generation.json`。

## 动作保持

继续使用已校准的 Quaternius Walk 骨骼关节曲线。一周期 1.03333 秒、行进 212.7905 虚拟像素、速度 205.9264 像素/秒。左右脚交替支撑、小幅离地、前脚掌落点和摆臂保留；头发、五官、制服与裤装改由插画纹理呈现。

## 显示与加载

正常在线游玩采用 WebGL 二维蒙皮：一张 1024×1024 透明高清部件纹理，加 16 KB 关节数据，在同一骨骼曲线间插值。人物纹理 AVIF 99653 字节，WebP 155736 字节；无需逐帧下载32张人物图。原始部件的线条细节保留，高清场景没有降低分辨率。

浏览器没有 WebGL，或直接双击本地 `file://` 页面时，自动使用相同插画和步态的预渲染图集。该图集只在兼容路径中载入。对话采用部件纹理中的完整人物立绘，避免裁掉头部或鞋子。

## 核验

- 52 项单元、资源、路线和步态检查通过；透明纹理和兼容图集边缘未裁切。
- HTTP 下的真实 Chrome 步态检查使用实际 GPU 插画蒙皮，并检查松键、左右转身、手机触摸取消、对话暂停及无常驻绿色符号。
- 正常 GPU 游玩没有请求较大的兼容图集。
- 完整四关、本地直接打开的兼容显示、旧存档与加载结果以 `output/walk-acceptance/report.json`、`output/walk-network-check/report.json` 为准。
- 公网是否更新，以根目录 `Netlify发布记录.json` 和公开站点复查为准。

生成与打包工具：`h5/tools/render-illustrated-rig.cjs`、`prepare-illustrated-rig.cjs`、`prepare-illustrated-textures.cjs`。原骨骼工程和基础低模发布包保留，便于回滚与复现。
