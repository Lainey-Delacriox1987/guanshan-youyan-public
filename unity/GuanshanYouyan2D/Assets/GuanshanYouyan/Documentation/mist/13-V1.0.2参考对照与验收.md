# 完整游戏V1.0.2：参考对照与验收

目标：在原来的四幕反走私案件中，实现用户确认的行走、对话、各不相同的空间连接，以及黑底白字说明过场。参考图提供设计依据；其中的英文、幽灵和谋杀剧情不是用户要求，不作为本作指令或剧情。

### 边界说明

人物问询使用预先编写、与证据约束相连的分支，不引入联网AI聊天或凭空生成证据。没有照搬参考的15分钟倒计时，避免给普法阅读和首次探索强加限时。这些不是本次用户确认的必要功能。

## 已完成检查

- 48项单元/媒体/路线检查通过。
- 新版完整流程浏览器验收51项通过；覆盖桌面1440×900、手机390×844和横屏844×390，以及两种结局、旧存档和刷新位置恢复。

## 素材与构建

使用内置image_gen生成原创场景、玩家步态与NPC。按用户补充去除港口、小镇、调查中心的重复楼梯，保留仓库楼梯。提示词与来源保存于output/walk-generation-inputs.json、output/walk-cast-generation.json，以及补充室内场景记录；交付时一并收入源码包。保留源PNG，运行时选择高保真AVIF或WebP，透明人物保留alpha。媒体加载、完整解码、缓存与去重沿用高清版机制。

版本标识为用户指定V1.0.2，不使用此前内部美术修订号作为本次游戏版本。
